Это портфолио собрано на Astro и TypeScript. Страницы генерируются при сборке: браузеру не нужно загружать большой фреймворк, чтобы показать текст и проекты.

## Контент отдельно от вёрстки

Каждый проект — Markdown-файл с названием, описанием, технологиями и статусом. Astro проверяет эти данные по схеме и создаёт отдельную страницу кейса. Так новый проект можно добавить без изменения компонентов.

## Собственный дизайн

В основе — обычный CSS с переменными для двух тем. Шрифты Onest и JetBrains Mono размещаются вместе с сайтом, поэтому при открытии страницы нет запросов в сторонний сервис шрифтов.

## Небольшие интерактивные детали

JavaScript отвечает за фильтры проектов, мобильное меню и переключение темы. Выбор темы сохраняется в браузере. Если JavaScript выключен, страницы и проекты остаются доступными.

## Контент и инструменты сборки

Основной контент написан в Markdown. Подключён MDX: при необходимости в описания можно добавлять компоненты. Astro Sitemap создаёт карту сайта при сборке с заданным адресом публикации. В проекте установлен Sass, а текущие стили написаны на обычном CSS.

<h2 id="deployment">Публикация через GitHub Pages</h2>

Портфолио опубликовано на GitHub Pages. После push в main workflow GitHub Actions устанавливает зависимости из lock-файла, проверяет Astro и TypeScript, собирает страницы и публикует каталог dist.

Сайт размещён в подпапке /Portfolio/. Общая функция путей добавляет этот префикс к страницам, изображениям и иконкам; canonical URL, Open Graph и sitemap используют тот же адрес. В локальном режиме сайт работает от корня.

Сборка для Pages проверена в браузере: внутренние переходы, загрузка изображений и иконок, метаданные, ссылки к контактам и переход из Markdown к странице образования.

Конфигурация Cloudflare Workers и Wrangler сохранена как альтернативный вариант развёртывания. Текущий хостинг — GitHub Pages.
