## О проекте

Lighthouse.by — сайт медицинского центра «Маяк Здоровья» в Минске. Я единственный разработчик проекта: самостоятельно сделал дизайн, frontend, backend и запуск. Разработка началась в феврале 2026 года; с 15 июня я работаю инженером-программистом в ООО «ЗАРГА Медика» и продолжаю поддерживать сайт.

Сайт работает на Laravel с отдельной административной панелью на Filament. Проект объединяет информацию об услугах, врачах, направлениях, чекапах, акциях и материалах клиники.

## Задача

Помочь посетителю разобраться в услугах клиники, найти нужного специалиста и перейти к записи. Для сотрудников — организовать управление связанным медицинским контентом через административную панель.

## Что реализовал

- **Каталог услуг и врачей.** Связанные страницы специалистов, направлений, услуг и чекапов; поиск по сайту.
- **Навигацию по симптомам.** Интерактивный выбор зоны тела помогает перейти к подходящему направлению.
- **Управление контентом.** Административную панель Filament для материалов клиники, врачей, услуг, акций и отзывов.
- **Интеграцию с медицинской системой.** Получение ближайших доступных слотов и переход во внешний сервис записи. Сам сайт не хранит записи на приём.
- **Формы и отзывы.** Валидацию обращений, согласия на обработку данных и модерацию отзывов.
- **Перенос данных.** Команды импорта врачей, услуг, материалов и изображений, а также сопоставление каталога.
- **SEO-инструменты.** Метаинформацию контента, команды аудита и отправки URL в IndexNow.

## Технические решения

**Backend:** PHP, Laravel, Filament, Eloquent. Данные врачей, услуг, направлений и публикаций связаны через модели и миграции MySQL.

**Frontend:** Blade, Livewire, JavaScript, Tailwind CSS и Vite. Интерфейсы адаптированы для просмотра с телефона и компьютера.

**Качество:** Unit, Feature и Browser тесты на Pest, браузерные сценарии с Playwright, статический анализ Larastan и форматирование Pint. В GitHub Actions предусмотрены отдельные шаги сборки и проверок, а MySQL запускается как сервис для тестовой базы.

**Развёртывание:** сценарий деплоя, проверка сборки фронтенда и документация запуска.

<h2 id="mis-integration">Технический кейс: недоступность медицинской системы</h2>

**Задача.** Показать ближайшие свободные окна из МИС и сохранить доступность каталога при сбое внешнего сервиса.

**Решение.** Отдельный Laravel HTTP Client проверяет структуру JSON и ограничивает время запроса. Успешный ответ каталога кэшируется на две минуты. После неудачной загрузки действует пауза 30 секунд: повторные открытия страниц не запускают запросы каталога заново. Для расписания источником свободного времени остаётся МИС.

**Результат.** При недоступности сервиса клиент возвращает состояние отсутствия данных. Посетитель может продолжить просмотр сайта; ошибки и повреждённые ответы обрабатываются отдельно. Поведение клиента проверяется тестами с подменёнными HTTP-ответами.

**Ограничение.** Локальные данные сайта не подтверждают свободный слот. Окончательную запись выполняет внешний сервис медицинской системы. Замеров изменения скорости после внедрения кэша пока нет.

<h2 id="seo">SEO и работа с контентом</h2>

Для страниц настроены метаинформация, canonical URL и структурированные данные Schema.org, включая информацию о клинике. Есть sitemap, robots.txt, консольный SEO-аудит и отправка адресов через IndexNow. Метаданные редактируются вместе с контентом в административной панели.

Это реализованные технические возможности сайта. Изменения поискового трафика и Core Web Vitals здесь не заявлены: для таких выводов нужны отдельные измерения.

## Результат

Сайт опубликован на lighthouse.by. Посетители могут искать услуги и врачей, изучать направления и переходить к записи; сотрудники клиники получили административную панель для работы с контентом.

Количественных данных о росте записей, конверсии и сравнении скорости до и после запуска пока нет. Здесь описаны реализованные возможности — метрики можно добавить после сбора аналитики.
