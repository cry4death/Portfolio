# Technology icons

Locally stored SVG assets extracted from Iconify JSON packages:

- logos: https://github.com/gilbarbara/logos — CC0-1.0
- simple-icons: https://github.com/simple-icons/simple-icons — CC0-1.0
- devicon: https://github.com/devicons/devicon — MIT, see LICENSE-devicon.txt
- lucide: https://github.com/lucide-icons/lucide — ISC, see LICENSE-lucide.txt

Exact icon identifiers are listed in sources.json. Logos preserve their original paths and colours. Generic concepts and tools without a dedicated logo in the selected collections use Lucide symbols, not invented brand logos. Riverpod, Dio, go_router and secure storage use state, network, route and lock symbols. Blade, Eloquent, Artisan, Laravel HTTP Client and Larastan use the Laravel family mark; Gutenberg uses WordPress and Wrangler uses the Cloudflare family mark.

Pest, PHPStan and Pint use assets downloaded directly from their official sites/repositories, with URLs in sources.json. PHPStan uses its original PNG favicon.

The square Pint symbol is extracted from the original SVG without changing its geometry. The unmodified wordmark is retained as pint-wordmark.svg.
